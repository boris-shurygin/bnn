# Инструкции для агентов

Единый источник правил этого проекта — `CLAUDE.md`. Не дублируй эти правила здесь.

Перед любой содержательной работой:

1. Полностью прочитай `CLAUDE.md`.
2. Изучи документы, на которые он ссылается для текущей задачи.
3. Проверь текущую ветку и состояние рабочего дерева.
4. Не изменяй и не удаляй чужие незавершённые правки.
