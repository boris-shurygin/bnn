# bnn — биологически правдоподобное локальное обучение

Хобби-исследование локальных three-factor правил обучения с сегрегированным
апикальным каналом как альтернативы backprop. Проверка на XOR и MNIST.

## Запуск

```bash
uv sync --group dev
uv run pytest

# один прогон
uv run python -m bioplast.runner configs/mnist_mlp_backprop.json

# свип: базовый конфиг × сетка значений → очередь → 3 процесса параллельно
uv run python -m bioplast.runner.sweep configs/xor_backprop.json --set seed=0,1,2 --out queue
uv run python -m bioplast.runner queue --workers 3

# графики из metrics.json
uv run python -m bioplast.viz runs --all

# локальный каталог прогонов и интерактивные графики
uv run uvicorn bioplast.viz.api:app --reload
# открыть http://127.0.0.1:8000/runs
```

Каждый прогон пишет в свою папку `runs/<id>/`: `config.json`, `metrics.json`,
`run.log`, `plots/*.png`. Ручных шагов нет ни одного — прогон полностью описан
конфигом.

## Имена прогонов

```
runs/20260808-095245-ses0.4-mnist-mlp-784-256-10-s0-bp/
     └──────┬──────┘ └─┬──┘ └─┬─┘ └──────┬───────┘ │  └┬┘
       дата и время  сессия  данные   модель      сид  комментарий
```

Метка времени идёт первой, поэтому сортировка папок по имени совпадает с
хронологической. Читаемые компоненты берутся из полей конфига `session`,
`dataset`, `model`, `seed`, `tag`; отсутствующие пропускаются.

Файлы конфигов в `queue/` именуются **без** метки времени
(`ses0.4-mnist-mlp-784-256-10-s0-bp-4d0835.json`): перегенерация свипа должна
перезаписывать те же файлы, а не плодить дубли. Шесть шестнадцатеричных
знаков — хеш конфига, он разводит варианты, различающиеся полями, которых нет
в читаемой части имени.

## Текущее состояние

Блок 0 закрыт: раннер с очередью, диагностика v0, графики, backprop-эталоны.
В блоке V готовы контракт артефактов, read-only API и браузерный просмотр
прогонов; следующий шаг — повторный запуск с изменённым конфигом.

| Эталон | Результат |
|---|---|
| XOR `2→8→1` | решается на всех 3 сидах, loss ~1e-5 |
| MNIST `784→256→10` | 98.06 / 98.08 / 97.90 % на тесте |
